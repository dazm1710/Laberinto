Laberinto - Python

Generador y resolvedor de laberintos en Python. Proyecto académico para practicar algoritmos y estructuras de datos.

🛠️ Stack
Python 3
Algoritmos de búsqueda (DFS / BFS)
Estructuras de datos (Matrices, Listas)
Programación modular

✨ Funcionalidades
Generación aleatoria de laberinto
Visualización en consola
Resolución automática del laberinto
Validación de caminos posibles

🚀 Cómo ejecutarlo
python laberinto.py

🧠 Qué aprendí
Implementación de algoritmos de recorrido de grafos
Manejo de matrices en Python
Diseño de lógica recursiva

🔜 Mejoras futuras
Visualización gráfica con Pygame
Exportar laberinto a imagen
Permitir al usuario jugar
